# MyDiary Desktop (v0.2.0)

선생님들을 위한 스마트 수업 일지 및 학생 성장 기록 관리 크로스 플랫폼 데스크톱 애플리케이션입니다.  
기존 스마트폰용 MyDiary 모바일 앱의 핵심 편의성과 데이터 호환성을 100% 계승하면서, 넓은 PC 모니터 화면에 특화된 와이드 시간표 매트릭스, 2열 마스터-디테일 에디터, 공문서 표준 한글(HWPX)/워드(DOCX) 내보내기 기능을 제공합니다.

## 🌟 주요 기능 (Key Features)

### 1. ▦ 주간 시간표 매트릭스 (Weekly Schedule Matrix)
- **시간대별 주간 전체 표**:
  - 세로 시간 축(오전 9시 ~ 저녁 8시)과 가로 7개 요일(월~일)을 한눈에 조망하는 A4/PDF 보고서 서식
  - **12:00 ~ 13:00 즐거운 점심 시간**: 가로 전체 병합 배너(🍱☕) 자동 표시
  - 오늘 날짜(Today) 시각적 강조 및 토/일 컬럼 색상 구분
- **원클릭 수업 일정 등록 & 편집 (`ScheduleModal`)**:
  - 빈 시간대 셀의 **`+`** 버튼을 누르면 해당 요일과 시간이 자동 세팅된 일정 등록 모달 호출
  - 학생 선택 시 과목, 수납 구분, 연락처, 주소 자동 완성
  - **특이사항 퀵 태그**: `+ => 이번주만`, `+ => 보강`, `+ => 시간변경`, `+ 휴강` 단축 입력 지원
  - 등록된 수업 카드 클릭 시 수정/삭제 및 **[수업 일지 작성 바로가기]** 지원
- **듀얼 뷰 모드 지원**:
  - `[▦ 주간 전체 표 (PDF 서식)]`: 시간대별 전체 조망
  - `[:= 요일별 상세 보기]`: 요일별 카드 리스트 뷰
- **주간 메모 박스**: 주간 주요 공지 및 학부모 상담 메모 개별 보관

### 2. 📝 수업 일지 (Class Diary)
- **2열 마스터-디테일 구조**: 좌측 학생 필터 및 과거 일지 목록, 우측 넓은 일지 에디터
- **체계적인 수업 기록**: 학습 진도, 과제 및 숙제, 수업 태도/특이사항 분리 기록
- **공문서 표준 출력**:
  - **한글 문서(HWPX)**: 국가 공공기관 및 학교 표준 OWPML 1.0 규격 HWPX 파일 즉시 생성 및 PC 파일 탐색기 저장
  - **워드 문서(DOCX)** & **A4 인쇄 / PDF 저장** 지원

### 3. 👥 학생 및 수강 차수 관리 (Student Management)
- **재원생 / 휴회생 필터링**: 활동 상태별 체계적인 학생 명단 관리
- **수강 차수(Term) 히스토리**: 학생별 1차, 2차 등 차수별 수업 시작일/종료일 및 기록 이력 추적
- **정규 요일/시간표 관리**: 학생 등록 시 요일별 기본 수업 시간대를 설정하면 주간 시간표에 자동 반영

### 4. 💾 데이터 백업 및 복원 (Backup & Restore)
- **모바일 완벽 호환**: 스마트폰 MyDiary 앱의 JSON 백업 파일을 데스크톱에서 그대로 복원하거나, 데스크톱 데이터를 모바일로 전송 가능
- **100% 로컬 오프라인 데이터 보안**: 외부 서버 전송 없이 로컬 스토리지에 안전하게 저장

### 5. 📖 시각적 도움말 가이드 (Visual Guide)
- **실제 실행 화면 캡처 기반 가이드**: 각 화면의 구성 요소와 사용법을 번호가 매겨진 스크린샷과 함께 친절하게 안내
- **단축키**: `F1` 키로 언제든 도움말 열람 가능, `ESC`로 닫기 지원

---

## ⌨️ 단축키 안내

| 단축키 | 기능 |
| :--- | :--- |
| **`F1`** | 시각적 도움말 가이드 열기 |
| **`ESC`** | 열려 있는 모달 (수업 일정, 도움말 등) 닫기 |
| **`Ctrl + P`** | 현재 화면 / 주간 보고서 인쇄 및 PDF 저장 |

## 🚀 개발 환경 실행

```bash
# 1. 패키지 설치
npm install

# 2. 웹 브라우저 개발 서버 실행 (http://localhost:5173/)
npm run dev

# 3. Electron 데스크톱 앱으로 실행
npm run dev:electron
```
