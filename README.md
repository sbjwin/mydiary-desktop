# MyDiary Desktop (v0.4.1)

선생님들을 위한 스마트 수업 일지 및 학생 성장 기록 관리 크로스 플랫폼 데스크톱 애플리케이션입니다.  
기존 스마트폰용 MyDiary 모바일 앱의 핵심 편의성과 데이터 호환성을 100% 계승하면서, 넓은 PC 모니터 화면에 특화된 와이드 시간표 매트릭스, 2열 마스터-디테일 에디터, 공문서 표준 한글(HWPX)/워드(DOCX) 내보내기, **스마트폰과 PC 간 구글 드라이브 원클릭 클라우드 데이터 동기화**, 그리고 **사용자 맞춤형 5대 다중 테마 시스템**을 제공합니다.

## 🌟 v0.4.1 주요 신규 기능 및 개선 사항

### 1. 📝 수업 일지 에디터 포커스 안정화 & 인라인 토스트 알림 도입 (신규)
- **Windows Electron 포커스 동결 버그 원천 해결**:
  - 기존 `window.alert()` OS 팝업 대화상자로 인해 저장 완료 후 웹뷰 포커스가 빠져나가 `textarea`에 마우스 클릭 및 키보드 입력이 차단되던 고질적인 포커스 락(Focus Lock) 결함을 완전히 제거했습니다.
  - OS 팝업 대신 부드럽고 세련된 **인라인 플로팅 토스트(`diary-toast-notice`) 알림**으로 전면 교체하여 포커스가 0.1초도 끊기지 않습니다.
- **연속 타이핑 포커스 자동 복원 메커니즘**:
  - [저장하기] 버튼을 누른 후에도 `window.focus()` 및 직전에 편집하던 입력 필드(`lastFocusedFieldRef`, `contentTextareaRef`)로 커서를 자동 복원하여, 손을 키보드에서 뗄 필요 없이 즉시 다음 문장을 수정할 수 있습니다.
- **실시간 저장 상태 마이크로 인터랙션**:
  - 저장 버튼 클릭 시 즉각적인 `✓ 저장 완료!` 녹색 피드백 애니메이션을 제공하여 작업 결과를 직관적으로 인지할 수 있습니다.
- **데이터 동기화 및 덮어쓰기 방지 (`loadData` 개선)**:
  - 저장 직후 최신 레코드 ID(`targetId`)를 최우선으로 동기화하여, 저장 후 다른 내용을 수정하더라도 이전 내용으로 되돌아가거나 폼이 리셋되지 않도록 완벽히 보장합니다.

### 2. 🎨 다중 감성 테마 시스템 & 2중 선택 GUI
- **5가지 프리셋 컬러 테마 제공**:
  - 🔵 **오션 블루 (Ocean Blue)**: 시원하고 신뢰감 있는 클래식 스카이 블루 (기본값)
  - 🟢 **포레스트 세이지 (Forest Sage)**: 장시간 일지 작성 시 눈이 편안한 에메랄드 & 세이지 그린
  - 🟣 **로열 라벤더 (Royal Lavender)**: 세련되고 감각적인 바이올렛 & 라벤더
  - 🟠 **웜 선셋 (Warm Sunset)**: 포근하고 생동감 넘치는 코랄 & 앰버 오렌지
  - ⚫ **미드나잇 다크 (Midnight Dark)**: 야간 업무 시 눈부심을 최소화하는 고대비 다크 모드
- **2중 테마 선택 GUI/UX 지원**:
  - **헤더 퀵 팔레트**: 상단 헤더 우측의 `[🎨 테마]` 버튼을 통해 작업 중 언제든 1클릭 팝오버로 즉시 테마 전환
  - **설정 탭 테마 센터**: [백업 및 설정] 탭에서 각 테마의 헤더, 사이드바, 본문 칩이 축소된 **미니 창 프리뷰 카드**를 보며 직관적으로 선택
- **실시간 반응 및 영속성 보장**:
  - 순수 CSS 변수 트랜지션으로 깜빡임 없이 부드러운 전환
  - 로컬 스토리지(`localStorage`) 자동 저장으로 프로그램을 재시작해도 선택한 테마 완벽 유지

### 2. ☁️ 구글 드라이브 클라우드 연동 및 스마트폰 동기화
- **구글 OAuth 2.0 PKCE 루프백 인증**: 외부 웹 브라우저를 통한 안전하고 간편한 구글 로그인 및 토큰 자동 갱신 지원
- **스마트폰 백업 원클릭 복원**: 스마트폰 MyDiary 앱에서 구글 드라이브(`appDataFolder`)로 백업한 `mydiary_backup.json`을 데스크톱에서 원클릭으로 다운로드 및 자동 복원
- **데스크톱 데이터 클라우드 백업**: 데스크톱의 최신 학생 명단, 수업 일지, 주간 계획을 구글 드라이브로 즉시 업로드
- **PC 로컬 JSON 백업/복원**: 인터넷 없이도 파일 탐색기를 통해 로컬 JSON 백업 파일 내보내기 및 가져오기 완벽 지원

### 2. ▦ 주간 시간표 매트릭스 & 양방향 스마트 연동
- **시간대별 주간 전체 표 (PDF 서식)**:
  - 세로 시간 축(오전 9시 ~ 저녁 8시)과 가로 7개 요일(월~일)을 한눈에 조망하는 와이드 매트릭스
  - **12:00 ~ 13:00 즐거운 점심 시간**: 가로 전체 병합 배너(🍱☕) 자동 표시
  - 오늘 날짜(Today) 강조 및 토/일 컬럼 색상 구분
- **수업 일정 등록/수정 모달 오버레이 UI 개편**:
  - 특이사항 퀵 태그(`+ => 이번주만`, `+ => 보강`, `+ => 시간변경`, `+ 휴강`) 지원
  - **수업 일지 양방향 스마트 연동**: 작성 완료된 수업 카드를 누르고 [수업 일지 작성]을 클릭하면 기존에 작성된 일지 내용을 자동으로 탐색하여 즉시 수정 모드로 연결
- **듀얼 뷰 모드**: `[▦ 주간 전체 표]` ↔ `[:= 요일별 상세 보기]` 원클릭 전환

### 3. 📝 2열 마스터-디테일 수업 일지 (Class Diary)
- **직관적인 2열 인터페이스**: 좌측 학생 필터 및 과거 일지 카드 목록, 우측 일지 작성/수정 폼
- **과거 일지 원클릭 수정**: 좌측 목록에서 지난 일지를 클릭하면 우측 폼에 기존 내용이 즉시 채워져 수정 가능
- **모바일/레거시 데이터 100% 호환**: 스마트폰 앱에서 작성된 다양한 형식의 일지 데이터 완벽 지원
- **공문서 표준 출력**:
  - **한글 문서(HWPX)**: 공공기관 및 학교 표준 OWPML 1.0 규격 HWPX 파일 즉시 생성 및 PC 파일 탐색기 저장
  - **워드 문서(DOCX)** & **A4 인쇄 / PDF 저장** 지원

### 4. 👥 학생 및 수강 차수 관리 (Student Management)
- **재원생 / 휴회생 탭 분리**: 상태별 체계적인 명단 조회 및 이름 실시간 검색
- **연락처 정규화**: 학생 및 학부모 전화번호 자동 정규화 `(본)010-XXXX`, `(모)010-XXXX`
- **수강 차수(Term) 이력 관리**: 차수별 수업 시작일/종료일 및 기록 이력 추적
- **정규 수업 기본 시간표**: 학생 프로필에 요일/시간을 등록하면 매주 주간 시간표에 자동 스케줄링

### 5. 🔐 Windows 자체 서명(Code Signing) 패키징 지원
- **자체 서명 인증서 자동화**: Windows SmartScreen 경고를 방지하는 코드 사이닝 인증서 생성 및 로컬 등록 스크립트 제공
- **환경 변수 기반 안전 빌드**: 보안 인증서와 비밀번호를 Git에 노출하지 않고 환경 변수로 안전하게 주입하여 빌드

## 🚀 개발 환경 실행

```bash
# 1. 패키지 설치
npm install

# 2. 웹 브라우저 개발 서버 실행 (http://localhost:5173/)
npm run dev

# 3. Electron 데스크톱 앱으로 실행
npm run dev:electron
```

## 📦 OS별 데스크톱 앱 패키징 (.exe / .dmg / .AppImage)

```bash
# Windows 일반 빌드 (x64 NSIS 설치 파일 및 포터블 .exe)
npm run package:win

npm run package:mac

npm run package:linux
```
